## 📌 What is this Project?

**InternHUB** is an AI-powered, full-stack web application designed to bridge the gap between students seeking internships and companies looking for qualified talent. Unlike traditional job boards that rely on manual searching and generic filters, InternHUB acts as an intelligent matchmaking platform. It automatically calculates a precise **Match Percentage** between a student's profile and every active internship posting, and enforces a **Dynamic AI Skill Assessment** before every application is finalized.

## 💡 Why this Project?

The traditional internship search process is often frustrating for both parties:
- **For Students:** They face "resume black holes", endlessly scrolling through irrelevant postings and applying to roles where they don't meet the core criteria, leading to high rejection rates and wasted time.
- **For Recruiters:** They are overwhelmed by hundreds of underqualified applications, making it incredibly difficult to spot the right talent manually.

**InternHUB solves this by:**
1. **Eliminating the noise:** Students only see internships where they have a strong statistical match.
2. **Automating the screening:** Recruiters instantly see a ranked list of applicants sorted by their AI assessment score, drastically reducing time-to-hire.
3. **Validating real knowledge:** A 15-question Groq-powered quiz proves a candidate's actual skill level before their application is accepted.
4. **Encouraging skill development:** By showing students their "Missing Skills" for a role, it provides actionable feedback on what they need to learn to improve their employability.

## ✨ Key Features

### For Students
- 🔍 **Smart Matching** — Ranked internship feed based on a 4-parameter weighted algorithm
- 🧠 **AI Skill Assessment** — 15 MCQs auto-generated by Groq's `llama3-8b-8192` for each specific role's required skills before every application
- ⏱️ **10-Minute Timer** — Timed quiz with auto-submit and live countdown
- 📊 **Profile Completion Wall** — Animated progress ring guides profile completion before matches are shown
- 📎 **Resume Upload** — Attach your resume to every application

### For Recruiters
- 📋 **Post Internships** — Specify required skills, CGPA bar, domain, location, and stipend
- 🏆 **Applicant Ranking** — Candidates sorted by **Assessment Score (0–15)** first, then by match percentage
- 🎨 **Score Badges** — Green (>10), orange (>5), red (≤5) pills for instant visual ranking

## 🧠 AI Skill Assessment Flow

```
Student clicks "Confirm & Apply Now"
        ↓
SkillAssessment overlay opens
        ↓ (~3–5 seconds)
Groq generates 15 MCQs tailored to the internship's required skills
        ↓
Student answers questions with a 10:00 countdown timer
        ↓
Clicks "Submit Assessment & Apply" (or timer auto-submits)
        ↓
Score calculated locally → POST /api/student/apply/{id} with assessmentScore
        ↓
Toast: "Application submitted! Score: X/15"
        ↓
Recruiter views applicants → sorted by score DESC (nulls last)
```

## 🧮 Matching Algorithm

| Parameter | Weight | Logic |
|-----------|:------:|-------|
| **Skill Match** | 50% | `(matched skills ÷ required skills) × 50` |
| **Domain Match** | 20% | Exact match = 20, else 0 |
| **CGPA Match** | 15% | Student CGPA ≥ Min CGPA = 15, else 0 |
| **Location Match** | 15% | City match or "Remote" = 15, else 0 |

**Example:** Student with React + Spring Boot applying for a Full-Stack Bengaluru role (Min CGPA 8.0, CGPA 8.5):
```
Skill: 4/4 × 50 = 50 | Domain: 20 | CGPA: 15 | Location: 15
                                          Total = 95% Match ✅
```

## ⚡ Quick Start

### Prerequisites

| Requirement | Version |
|-------------|---------|
| Java | 17+ |
| Node.js | 18+ |
| MySQL | 8.0+ |
| Groq API Key | Free at [console.groq.com](https://console.groq.com) |

### 1 — Database

```sql
CREATE DATABASE internhub_db;
```

### 2 — Backend

```bash
cd backend

# Update MySQL password if needed:
# backend/src/main/resources/application.properties
#   spring.datasource.password=YOUR_PASSWORD

# Windows
.\mvnw.cmd spring-boot:run

# Linux / Mac
./mvnw spring-boot:run
```
→ API running at **http://localhost:8080**

### 3 — Frontend

```bash
cd frontend
npm install
```

Add your Groq API key to `frontend/.env`:
```env
VITE_API_URL=http://localhost:8080/api
VITE_GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxx
```

```bash
npm run dev
```
→ App running at **http://localhost:5173**

> 💡 Get a free Groq API key at **[console.groq.com](https://console.groq.com)** → API Keys tab. The free tier is generous enough for development.

### 4 — Stopping the Application

Press `Ctrl + C` in each terminal. To forcefully free ports:

```powershell
# Windows (PowerShell)
Stop-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess -Force
Stop-Process -Id (Get-NetTCPConnection -LocalPort 5173).OwningProcess -Force
```

*(Or: `npx kill-port 8080` and `npx kill-port 5173`)*
